# Security policy

Report security vulnerabilities **privately**, not in public issues.

## Report

Use [GitHub Security Advisories](https://github.com/eriknn/ha-pax_ble/security/advisories/new) on this repository.

If you cannot use advisories, open **Report a security vulnerability** under Issues and keep details minimal — maintainers will follow up privately.

## Scope

This integration runs locally on your Home Assistant instance and talks to fans over Bluetooth. Reports about PIN handling, unsafe defaults, or trust boundaries in the integration code are in scope.

General Home Assistant, HACS, or ESPHome vulnerabilities should be reported to those projects unless this integration is the root cause.
